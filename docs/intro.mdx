# 欢迎来到《电力电子教材》

这个站点是教材仓库的起始骨架，用来逐步承载课程目录、章节正文、公式说明、插图与实验资料。

## 当前已完成

- 建立了可直接运行的 Docusaurus 工程
- 配置了中文站点信息与 GitHub 仓库地址
- 提供了欢迎首页与第一篇起始文档

## 建议的后续编排

1. 在 `docs/` 下按章创建文档，例如 `chapter-01-overview.mdx`
2. 将电路图、封面和插图放在 `static/img/`
3. 如果需要数学公式，可直接在 MDX 中使用 KaTeX 语法
4. 在 `sidebars.ts` 中逐步细化章节导航

## 本地启动

```bash
npm install
npm run start
```

## 生产构建

```bash
npm run build
```

## 内容约定

- 首页用于项目欢迎与导航，不承载长篇教材正文
- 正文建议放在 `docs/`
- 若以后接入部署，可直接指向 GitHub Pages
